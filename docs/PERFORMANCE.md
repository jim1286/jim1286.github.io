# 성과 탭

2026-10-21 사용자 요청: 제품 다음에 통합·앱별 성과를 HJM으로 표시한다. 주요 지표만 공개하며
모펀·태그라운드·포트폴리오 웹은 제외한다. 별도 HTML 보고서는 만들지 않는다.

## 화면과 데이터

- `src/PerformancePanel.tsx`: `#performance` 및 `#performance/<app-id>`. HJM Tabs, SegmentedControl, StatisticGroup,
  Card, LineChart, ChartLegend, Timeline, DataTable, Collapsible을 사용한다. 제품 전용 차트 renderer·CSS는 없다.
- 기본 지표는 활성 사용자·신규 사용자·스토어 방문·예상 광고 수익이다. 설치 사용자와 수집 현황은 펼침에서만 읽는다.
- `src/performance/data.ts`: 최신 확보 관측, 날짜 축, 최신 출처 선택과 같은 날짜 정의의 증감 계산.
- `src/performance/history.ts`: 아래 원본에서 확인한 주요 지표의 과거 집계값. 원본 콘솔 URL·속성/계정 ID·로그는 포함하지 않는다.
- `src/performance/storeHistory.ts`: 10/21 Aside CLI에서 두 스토어 로그인·실제 보고서 접근 후 내보낸 집계값.
  기준일과 수집일은 다르며 최신 수집 시각은 파일의 `storeCapturedAt`에 보존한다.
- Google Play 오늘야구 DAU는 2025-08-10–2026-10-14의 339개 실제 관측이다. 선택의창 DAU는
  2026-02-14–03-04 중 15개 관측만 제공됐으므로 이후 날짜를 0으로 채우지 않는다.
- Apple 제품 페이지 조회는 오늘야구 2025-08-06–2026-10-19(440일), 선택의창 2026-02-16–10-19(246일),
  번뚝·다에리·Spint·비행중은 현재 7/22–10/19(90일)이다. 90일을 해당 앱의 전체 역사로 단정하지 않는다.
  Utilverse는 App Analytics 미제공으로 미확보다.
- Play 방문자는 오늘야구·선택의창 2025-11-08–2026-10-18(각345일), Utilverse·Spint 9/01–10/18(각48일)이다.
  다른 앱과 더 오래된 기간은 수집 중이다. 내보내기에서 제공하지 않은 날짜는 공백이다.
- 오늘야구 Play 설치 사용자 내보내기는 2021-10-22부터 명시적 0을 포함한다. 최초 양수는 2025-08-10이나
  내보내기 시작일이나 최초 양수가 출시일을 증명하지 않는다. `INSTALLED_USERS_LAST_30D`는 DAU가 아니다.
- GA4 기존 자료는 10/02–12, AdMob는 10/20까지 확보된 주요 관측만 사용한다.

통합 화면은 7개 앱의 최신 확보값을 나란히 보여 준다. 전체 고유 사용자 합계는 만들지 않는다.
AdMob 공식 9/21–10/20 계정 전체 예상 수익 USD 0.10은 내부 근거에만 보존한다. 제외 제품 포함 여부가 입증되지 않아 공개 통합 수익이나 그래프에 사용하지 않는다.
앱별 수익은 관측된 OS/광고 행의 반올림 잠정값이며 모든 플랫폼·국가·광고 형식의 앱 총액으로 확대하지 않는다.
선택의창 10/20은 한국 iOS 배너이고, 과거 iOS 광고 행은 다른 국가도 있어 별도 계열이다.

## 갱신과 계산 경계

오전 8:30 수집 자료를 오전 9시 발전 이력·사이트 갱신 작업에서 대조한다. 새 근거가 있으면
기존 series의 앱·출처·지표·OS/국가/광고 범위·통화·시간대를 유지해 관측을 추가하고, 달라지면 별도 series로 둔다.
수집일과 성과 기준일을 보존하고 잠정값의 후속 수정은 원래 날짜의 수정으로 기록한다.

- GA4 활성 사용자와 Play DAU는 출처 선택으로 분리한다. 서로 이어 붙이거나 더하지 않는다.
- 날짜별 축의 미관측은 `null`, 실제 확인된 사용자 0은 `0`이다. 빈 구간을 연결·보간하지 않는다.
- 증감은 같은 series의 정확한 전일이 있을 때만 계산한다. 분모 0은 비율을 계산하지 않는다.
- 반올림 수익은 증감률·정확한 누적을 계산하지 않는다. 공식 기간 총계는 별도 보존한다.
- 신규 사용자는 가입자가 아니며 설치 사용자는 신규 다운로드가 아니다.
- 개발 이력 날짜는 공개 배포일이 아니다. 같은 길이·정의·범위의 전후 관측이 없으면 비교하지 않는다.
  주요 이력과 관측을 함께 보여 주는 것으로 개선의 인과·효과를 주장하지 않는다.
- Play 방문자는 일별 고유 사용자(다른 기기에 이미 앱을 설치한 방문자 제외), Apple 제품 페이지 조회는 비고유 조회 횟수다.
  출처 선택으로 분리하고 합산하지 않는다. 노출·다운로드와도 다르다.
- iOS 사용자와 Apple 활성 기기는 서로 다른 단위다. 오늘야구는 GA4 운영체제=iOS 필터로
  2025-08-04–12-31에서146일, 2026-09-01–10-20의50일을 확보했다(`iosHistory.ts`).
  2026-01-01–08-31은 아직 수집 중이다. 비행중은 2026-10-10–17 중 실제 반환된 4일 관측을 확보했고 나머지 기간을 조회 중이다. 출처 선택에서 OS 통합/Android와 분리한다.
  다른 앱과 더 오래된 기간, Apple 활성 기기는 조회 중이며 수집 전까지 수익·다운로드로 대체하지 않는다.
